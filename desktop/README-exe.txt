행운볼 레이스 (exe 버전)

■ 실행
  압축을 모두 푼 뒤 LuckyBallRace.exe 를 더블클릭하세요.
  브라우저 없이 단독 창으로 실행되고, 인터넷이 없어도 됩니다.
  (압축 파일 안에서 바로 실행하면 동작하지 않습니다. 반드시 압축을 푸세요.)

■ 바탕화면 아이콘 만들기
  LuckyBallRace.exe 를 마우스 오른쪽 단추로 누르고
  보내기 → 바탕 화면에 바로 가기 만들기 를 고르세요.

■ 조작
  F11: 전체 화면 켜기/끄기, F5: 처음 화면으로 새로 고침

■ 참고
  - 처음 실행할 때 Windows 보안 경고(SmartScreen)가 뜨면 "추가 정보" → "실행"을 누르세요.
    인증서로 서명하지 않은 프로그램이라 나오는 안내입니다.
  - 폴더 안의 다른 파일(dll, pak 등)도 실행에 필요하니 지우지 마세요.
  - 삭제할 때는 폴더를 통째로 지우면 됩니다.
