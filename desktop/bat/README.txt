행운볼 레이스 (bat 버전)

■ 바로 실행
  LuckyBallRace.bat 을 더블클릭하세요.
  Edge(없으면 크롬)가 주소창 없는 앱 창으로 게임을 엽니다.

■ 내 PC에 설치 (바탕화면 아이콘 만들기)
  Install.bat 을 더블클릭하세요.
  게임이 %LocalAppData%\LuckyBallRace 에 복사되고,
  바탕화면과 시작 메뉴에 "행운볼 레이스" 바로가기가 생깁니다.
  관리자 권한은 필요 없습니다.

■ 삭제
  설치 폴더의 Uninstall.bat 을 실행하세요.

■ 참고
  - 인터넷 없이도 실행됩니다.
  - Windows 보안 경고(SmartScreen)가 뜨면 "추가 정보" → "실행"을 누르세요.
  - 최근 입력한 이름과 설정은 브라우저 저장소에 남습니다.
