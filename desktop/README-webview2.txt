행운볼 레이스 (exe 버전)

■ 실행
  LuckyBallRace.exe 를 더블클릭하세요. 설치 과정 없이 바로 창이 열립니다.
  원하는 폴더(예: 바탕화면, 문서)에 두고 쓰면 됩니다.

■ 바탕화면 아이콘 만들기
  LuckyBallRace.exe 를 마우스 오른쪽 단추로 누르고
  보내기 → 바탕 화면에 바로 가기 만들기 를 고르세요.

■ 필요한 것
  Windows 10 / 11 (64비트).
  화면은 Windows에 들어 있는 Microsoft Edge WebView2 로 그립니다.
  Windows 11과 최신 업데이트된 Windows 10에는 이미 들어 있습니다.
  만약 없으면 게임이 기본 브라우저로 열립니다.
  (WebView2 런타임: https://developer.microsoft.com/microsoft-edge/webview2/ 에서 무료로 설치)

■ 참고
  - 처음 실행할 때 Windows 보안 경고(SmartScreen)가 뜨면 "추가 정보" → "실행"을 누르세요.
    인증서로 서명하지 않은 프로그램이라 나오는 안내입니다.
  - 최근 입력한 이름과 설정은 %LocalAppData%\LuckyBallRace 에 저장됩니다.
  - 삭제할 때는 exe 파일과 %LocalAppData%\LuckyBallRace 폴더를 지우면 됩니다.
