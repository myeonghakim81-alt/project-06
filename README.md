# 행운볼 레이스

참가자 이름을 넣으면 공들이 긴 트랙을 위에서 아래로 내려오며 경주합니다. 결승선에 도착한 순서로 행운의 주인공을 정합니다.

## 실행 방법

`lucky-ball-race.html` 파일 하나만 있으면 됩니다. 파일을 더블클릭하면 브라우저(크롬, 엣지, 사파리, 파이어폭스)에서 바로 실행됩니다. 서버나 설치가 필요 없고, 인터넷이 없어도 동작합니다(인터넷이 연결되어 있으면 제목 글꼴만 추가로 내려받습니다).

## 설정 항목

| 번호 | 항목 | 선택지 |
|---|---|---|
| 1 | 참가 인원 | 2~500명 |
| 2 | 이름 · 공 꾸미기 | 이름, 공 색, 공 이미지, 가중치(`이름*3` → 공 3개) |
| 3 | 레이스 시간 | 30초 · 60초 · 90초 (시간에 맞춰 코스 길이가 정해짐) |
| 4 | 레이스 스타일 | 익사이팅 · 드라마틱 |
| 5 | 난이도 | 쉬움 · 보통 · 어려움 |
| 6 | 테마 | 캐주얼 파스텔 · 네온 아케이드 · 심플 미니멀 · 레트로 우드 · 우주 |
| 7 | 당첨 형태 | 1등 · N등 · 상위 N명 · 하위 N명 · 꼴찌 · 전체 순위 · 블라인드 |
| 8 | 슬로모션 | 끔 · 적게 · 보통 · 많이 |
| 고급 | 시드 번호, 효과음, 이름표 | 같은 시드 + 같은 참가자 + 같은 설정이면 같은 레이스가 나옵니다 |

- **이미지 공**: 이름 옆 사진 칸을 눌러 한 장씩 넣거나, "이미지 여러 장"으로 한꺼번에 올립니다. 파일 이름이 참가자 이름과 같으면(예: `민수.png`) 그 공에 자동으로 연결되고, 남은 이미지는 사진이 없는 공에 순서대로 들어갑니다. 이미지를 넣은 공은 레이스 내내 이미지로 보입니다.
- **같은 이름**: 허용합니다. 두 번째부터 `민수(2)`처럼 번호가 붙습니다.

## 코스

출발 상자 → 여러 구간 → 마지막 깔때기 → 결승선 순서로 시드에 따라 매번 새로 만들어집니다. 구간 종류는 다음과 같습니다.

- **넓은 구간**: 넓은 직선 내리막, 광장 · 갈림길(중앙 섬), 회전 바 광장, 범퍼 분지, 기둥 숲
- **좁은 구간**: 좁은 협곡, 3갈래 레인, 계단 턱, 물결 협로
- **곡선 구간**: S자 연속 곡선, 롱 커브, 지그재그 내리막

익사이팅은 장애물 구간이, 드라마틱은 곡선과 협곡 구간이 더 많이 나옵니다.

## 공정성

- 출발 순서는 입력 순서와 상관없이 무작위로 섞습니다.
- 모든 공은 크기 · 무게 · 탄성이 같습니다. 이미지는 겉모습만 바꿉니다.
- 레이스는 한 번만 계산되고 그대로 재생됩니다. 화면보다 몇 초 앞서 계산하는 것은 슬로모션과 카메라 연출을 위해서이며 결과를 바꾸지 않습니다.
- 시작 전에 공 몇 개로 같은 코스를 미리 굴려 보고 재생 속도를 맞춥니다. 이것도 결과와는 무관합니다.

## 개발

```
src/index.html   화면 뼈대
src/style.css    테마별 스타일
src/engine.js    코스 생성 · 물리 · 당첨 판정 · 슬로모션 일정 (DOM 없음)
src/app.js       설정 화면 · 렌더링 · 카메라 · 효과음 · 결과
tools/build.cjs  src/ 를 lucky-ball-race.html 하나로 묶기
tools/sim.cjs    화면 없이 레이스를 돌려 시간 · 끼임 · 성능 확인
tools/e2e.cjs    Playwright로 설정 → 레이스 → 결과까지 자동 실행
```

`src/` 를 고친 뒤에는 `node tools/build.cjs` 로 `lucky-ball-race.html` 을 다시 만듭니다.

```
node tools/build.cjs
node tools/sim.cjs 100 60 dramatic normal 3      # 인원 시간 스타일 난이도 시드개수
node tools/e2e.cjs ./shots 12 bottom pastel 30   # Playwright 필요
```
