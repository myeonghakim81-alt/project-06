# 행운볼 레이스

참가자 이름을 넣으면 공들이 긴 트랙을 위에서 아래로 내려오며 경주합니다. 결승선에 도착한 순서로 행운의 주인공을 정합니다.

## 실행 방법

`lucky-ball-race.html` 파일 하나만 있으면 됩니다. 파일을 더블클릭하면 브라우저(크롬, 엣지, 사파리, 파이어폭스)에서 바로 실행됩니다. 서버나 설치가 필요 없고, 인터넷이 없어도 동작합니다(인터넷이 연결되어 있으면 제목 글꼴만 추가로 내려받습니다).

### Windows 프로그램으로 쓰기

`bash tools/build-windows.sh` 를 실행하면 `dist/` 에 두 가지 배포 파일이 만들어집니다.

| 파일 | 크기 | 내용 |
|---|---|---|
| `LuckyBallRace-exe.zip` | 약 1.2MB | `LuckyBallRace.exe` 하나(약 3MB). 더블클릭하면 단독 창으로 실행됩니다. Windows 10/11에 들어 있는 WebView2(Edge 엔진)로 그리고, 없으면 기본 브라우저로 엽니다. 만들려면 Go가 필요합니다. |
| `LuckyBallRace-bat.zip` | 약 80KB | 게임 + `LuckyBallRace.bat`(실행) · `Install.bat`(바탕화면 · 시작 메뉴 바로가기) · `Uninstall.bat`. Windows에 기본으로 있는 Edge를 주소창 없는 앱 창으로 엽니다. |
| `LuckyBallRace-win64.zip` | 약 95MB | Electron 단독 실행 버전. `ELECTRON=1 bash tools/build-windows.sh` 로 만들 때만 생깁니다. |

둘 다 코드 서명을 하지 않아서 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. "추가 정보" → "실행"을 누르면 됩니다.

## 설정 항목

| 번호 | 항목 | 선택지 |
|---|---|---|
| 1 | 참가 인원 | 2~500명 |
| 2 | 이름 · 공 꾸미기 | 이름, 공 색, 공 이미지, 가중치(`이름*3` → 공 3개) |
| 3 | 레이스 시간 | 30초 · 60초 · 90초 (시간에 맞춰 코스 길이가 정해짐) |
| 4 | 레이스 스타일 | 익사이팅 · 드라마틱 |
| 5 | 난이도 | 쉬움 · 보통 · 어려움 |
| 6 | 테마 | 캐주얼 파스텔 · 네온 아케이드 · 심플 미니멀 · 레트로 우드 · 우주 |
| 7 | 당첨 형태 | 1등 · N등 · 상위 N명 · 하위 N명 · 꼴찌 · 전체 순위 · 블라인드 · 단계별 추첨 |
| 8 | 슬로모션 | 끔 · 적게 · 보통 · 많이 |
| 고급 | 시드 번호, 효과음, 이름표 | 같은 시드 + 같은 참가자 + 같은 설정이면 같은 레이스가 나옵니다 |

- **이미지 공**: 이름 옆 사진 칸을 눌러 한 장씩 넣거나, "이미지 여러 장"으로 한꺼번에 올립니다. 파일 이름이 참가자 이름과 같으면(예: `민수.png`) 그 공에 자동으로 연결되고, 남은 이미지는 사진이 없는 공에 순서대로 들어갑니다. 이미지를 넣은 공은 레이스 내내 이미지로 보입니다.
- **같은 이름**: 허용합니다. 두 번째부터 `민수(2)`처럼 번호가 붙습니다.
- **단계별 추첨**: 등수별 인원을 정하면(기본 5등 5명 · 4등 4명 · 3등 3명 · 2등 2명 · 1등 1명) 코스를 등분한 지점마다 낮은 등수부터 뽑습니다. 5등은 1/5 지점, 4등은 2/5 지점 … 1등은 결승선입니다. 각 지점에 먼저 도착한 공이 정해진 인원만큼 트랙 옆 당첨 칸으로 빠지고, 나머지는 계속 달립니다. 공이 여러 개인 사람이 뽑히면 그 사람의 나머지 공은 레이스에서 빠집니다. 등수 개수(2~8)와 등수별 인원은 설정 화면에서 바꿀 수 있습니다.

## 코스

출발 상자 → 여러 구간 → 마지막 깔때기 → 결승선 순서로 시드에 따라 매번 새로 만들어집니다. 구간 종류는 다음과 같습니다.

- **넓은 구간**: 넓은 직선 내리막(풍차), 광장 · 갈림길(중앙 섬), 회전 바 광장(풍차 2~4개), 범퍼 분지(풍차), 기둥 숲, 소용돌이 접시, 지름길 · 타이밍 문
- **좁은 구간**: 좁은 협곡, 3갈래 레인, 갈래길 · 합류(3~4갈래로 나뉘었다 다시 모임), 계단 턱, 물결 협로, 감속 늪, 가속 패드
- **곡선 구간**: S자 연속 곡선, 롱 커브(풍차), 지그재그 내리막(꺾일 때마다 풍차)
- 결승선 바로 앞 협로에도 풍차가 하나 있습니다.

순위를 뒤집는 장치는 다음과 같습니다. 순간이동은 없습니다.

| 장치 | 동작 |
|---|---|
| 풍차 | 날개 4개가 돌면서 공을 쳐냄 |
| 가속 패드 | 밟은 공만 순간적으로 빨라짐 |
| 소용돌이 접시 | 접시 안에서 돌다가 공마다 다른 시간 뒤에 풀려남 |
| 지름길 · 타이밍 문 | 짧은 길은 일정 간격으로 열리고 닫히는 문, 긴 길은 기둥이 있어 조금 느림 |
| 감속 늪 | 늪 위를 지나는 공은 느려짐 |
| 갈래길 · 합류 | 갈래마다 풍차 · 범퍼 · 기둥 · 빈 길이 섞여 있어 어느 길로 들어가느냐에 따라 순위가 바뀜 |

익사이팅은 장애물 · 가속 장치가, 드라마틱은 곡선 · 갈래길 · 소용돌이가 더 많이 나옵니다.

## 공정성

- 출발 순서는 입력 순서와 상관없이 무작위로 섞습니다.
- 모든 공은 크기 · 무게 · 탄성이 같습니다. 이미지는 겉모습만 바꿉니다.
- 공이 장애물 사이에 오래 끼면 앞뒤로 살짝 튕겨 주고, 그래도 안 빠지면 잠깐 다른 공 · 장애물을 통과시켜 빼냅니다. 모든 공에 같은 규칙이 적용됩니다.
- 레이스는 한 번만 계산되고 그대로 재생됩니다. 화면보다 몇 초 앞서 계산하는 것은 슬로모션과 카메라 연출을 위해서이며 결과를 바꾸지 않습니다.
- 시작 전에 공 몇 개로 같은 코스를 미리 굴려 보고 재생 속도를 맞춥니다. 이것도 결과와는 무관합니다.

## 개발

```
src/index.html   화면 뼈대
src/style.css    테마별 스타일
src/engine.js    코스 생성 · 물리 · 당첨 판정 · 슬로모션 일정 (DOM 없음)
src/app.js       설정 화면 · 렌더링 · 카메라 · 효과음 · 결과
tools/build.cjs  src/ 를 lucky-ball-race.html 하나로 묶기
tools/sim.cjs    화면 없이 레이스를 돌려 시간 · 끼임 · 성능 확인
tools/e2e.cjs    Playwright로 설정 → 레이스 → 결과까지 자동 실행
tools/build-windows.sh  Windows용 bat / exe 배포 파일 만들기
desktop/         exe(WebView2 · Electron) 창 코드, bat 실행·설치 파일, 아이콘
```

`src/` 를 고친 뒤에는 `node tools/build.cjs` 로 `lucky-ball-race.html` 을 다시 만듭니다.

```
node tools/build.cjs
node tools/sim.cjs 100 60 dramatic normal 3      # 인원 시간 스타일 난이도 시드개수
node tools/e2e.cjs ./shots 12 bottom pastel 30   # Playwright 필요
```
